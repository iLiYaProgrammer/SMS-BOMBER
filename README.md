---

🚀 نصب و اجرا

```bash
git clone https://github.com/iLiYaProgrammer/sms-bomber.git
cd sms-bomber
pip install -r requirements.txt
python3 bomber.py
```

اگر requests نصب نباشد، خودکار نصب می‌شود.

---

📦 کتابخانه‌های مورد نیاز

· requests : pip install requests
· urllib3 : pip install urllib3

یا نصب همزمان:

```bash
pip install requests urllib3
```

🐛 عیب‌یابی

· ModuleNotFoundError: با دستور pip install requests urllib3 کتابخانه‌ها را نصب کنید.
· پاسخ نمی‌دهد: اینترنت یا VPN خود را بررسی کنید.
· Timeout: مقدار Sleep Time را بیشتر کنید.
· خطای ترمینال ویندوز: از cmd یا PowerShell استفاده کنید.
